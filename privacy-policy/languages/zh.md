# 隐私政策

**生效日期：** 2026年7月26日

## 1. 简介

欢迎使用 "Assistant for Fate"（以下简称"应用"）。您的隐私对我们非常重要。本隐私政策解释了当您使用我们的应用时，我们如何处理您的信息。

## 2. 数据收集

该应用不会收集用户的任何个人数据。我们不会要求、存储或传输任何个人信息，例如姓名、电子邮件地址或联系方式。您的角色和设置绝不会离开您的设备。

该应用连接互联网只有一个目的：下载可选的社区模组（mod）及其目录，具体见第5节说明。这些请求绝不包含您的角色数据、设置或任何个人信息。

## 3. 数据存储

与您的角色和偏好（例如主题、语言、掷骰子设置、已安装的模组）相关的所有数据都存储在您的设备本地，使用浏览器的内部存储机制，如 Local Storage 和 IndexedDB。这些数据仅保存在您的设备上，无法被我们或第三方访问。

## 4. 用户控制

您完全可以在应用内控制您的数据。您可以通过应用的用户界面更新或删除您的角色、偏好设置和已安装的模组。此外，您还可以通过设备设置清除所有应用数据。

## 5. 网络连接与第三方内容

该应用支持由社区创建的可选模组。为了提供这些模组，应用会执行以下网络请求：

- **模组目录刷新（自动）：** 应用启动时，会从托管在 GitHub Pages（`stanislavsonder.github.io/fate-mods`）上的官方模组注册表下载公开的模组目录。这样可以使 Mod Store 中的列表保持最新。
- **浏览 Mod Store（由您的操作触发）：** 在 Mod Store 中打开某个模组的页面，会从同一注册表下载该模组的描述信息。
- **安装模组（由您的操作触发）：** 安装模组——无论是从 Mod Store 还是从您自行提供的 URL——都会从注册表或该 URL 下载该模组的文件（其清单、代码包和翻译文件）。

这些都是普通的下载请求。它们不携带任何角色数据、设置信息，也不含应用添加的任何标识符。与任何互联网连接一样，托管服务提供商（GitHub，或您提供的 URL 的主机）在技术上可以看到标准的连接元数据，例如您的 IP 地址；这受该提供商自身隐私政策的约束，而非我们的政策。

该应用不包含任何分析工具、广告或任何形式的跟踪。我们不会与第三方共享任何数据，也不会为第三方收集任何数据。

## 6. 儿童隐私

该应用适用于所有年龄段的用户，不包含需要年龄限制的内容。

## 7. 隐私政策更新

我们可能会不时更新本隐私政策。重大更改将在您更新应用后的首次启动时通过对话窗口通知您。
