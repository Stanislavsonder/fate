# Kebijakan Privasi

**Tanggal Berlaku:** 7 September 2026

## 1. Pengantar

Selamat datang di "Assistant for Fate" ("Aplikasi"). Privasi Anda penting bagi kami. Kebijakan Privasi ini menjelaskan bagaimana kami menangani informasi Anda saat menggunakan Aplikasi kami.

## 2. Pengumpulan Data

Aplikasi ini tidak mengumpulkan data pribadi pengguna. Kami tidak meminta, menyimpan, atau mentransfer informasi pribadi seperti nama, alamat email, atau detail kontak lainnya. Karakter dan pengaturan Anda tidak pernah meninggalkan perangkat Anda.

Aplikasi ini terhubung ke internet untuk satu tujuan saja: mengunduh mod komunitas opsional beserta katalognya, sebagaimana dijelaskan di Bagian 5. Permintaan ini tidak pernah menyertakan data karakter, pengaturan, atau informasi pribadi Anda.

## 3. Penyimpanan Data

Semua data yang terkait dengan karakter dan preferensi Anda (misalnya, tema, bahasa, pengaturan lemparan dadu, mod yang terpasang) disimpan secara lokal di perangkat Anda menggunakan mekanisme penyimpanan internal browser seperti Local Storage dan IndexedDB. Data ini tetap ada di perangkat Anda dan tidak dapat diakses oleh kami atau pihak ketiga.

## 4. Kontrol Pengguna

Anda memiliki kendali penuh atas data Anda di dalam Aplikasi. Anda dapat memperbarui atau menghapus karakter, preferensi, dan mod terpasang Anda melalui antarmuka pengguna Aplikasi. Selain itu, Anda dapat menghapus semua data Aplikasi melalui pengaturan perangkat Anda.

## 5. Koneksi Jaringan dan Konten Pihak Ketiga

Aplikasi ini mendukung mod opsional buatan komunitas. Untuk menyediakannya, Aplikasi melakukan permintaan jaringan berikut:

- **Penyegaran katalog mod (otomatis):** saat Aplikasi dimulai, Aplikasi mengunduh katalog mod publik dari registri mod resmi, yang dihosting di GitHub Pages (`stanislavsonder.github.io/fate-mods`). Ini menjaga daftar di Mod Store tetap terkini.
- **Menjelajahi Mod Store (atas tindakan Anda):** membuka halaman sebuah mod di Mod Store akan mengunduh deskripsi mod tersebut dari registri yang sama.
- **Pemasangan mod (atas tindakan Anda):** memasang sebuah mod — dari Mod Store atau dari URL yang Anda berikan sendiri — akan mengunduh berkas mod tersebut (manifes, paket kode, dan terjemahannya) dari registri atau dari URL tersebut.

Ini adalah permintaan unduhan biasa. Permintaan ini tidak membawa data karakter, pengaturan, atau pengidentifikasi apa pun yang ditambahkan oleh Aplikasi. Seperti halnya koneksi internet lainnya, penyedia hosting (GitHub, atau host dari URL yang Anda berikan) secara teknis dapat melihat metadata koneksi standar seperti alamat IP Anda; hal ini diatur oleh kebijakan privasi penyedia tersebut sendiri, bukan oleh kami.

Aplikasi ini tidak mengandung analitik, iklan, atau pelacakan dalam bentuk apa pun. Tidak ada data yang dibagikan kepada pihak ketiga atau dikumpulkan oleh kami untuk kepentingan mereka.

## 6. Privasi Anak

Aplikasi ini cocok untuk pengguna dari segala usia dan tidak mengandung konten yang memerlukan batasan usia.
