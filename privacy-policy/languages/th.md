# นโยบายความเป็นส่วนตัว

**วันที่มีผลบังคับใช้:** 26 กรกฎาคม 2026

## 1. บทนำ

ยินดีต้อนรับสู่ "Assistant for Fate" ("แอปพลิเคชัน") ความเป็นส่วนตัวของคุณสำคัญสำหรับเรา นโยบายความเป็นส่วนตัวนี้อธิบายวิธีที่เราจัดการข้อมูลของคุณเมื่อคุณใช้แอปพลิเคชันของเรา

## 2. การเก็บรวบรวมข้อมูล

แอปพลิเคชันนี้ไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ เราไม่ขอ เก็บ หรือส่งข้อมูลส่วนบุคคล เช่น ชื่อ ที่อยู่อีเมล หรือข้อมูลการติดต่อ ตัวละครและการตั้งค่าของคุณจะไม่ถูกส่งออกจากอุปกรณ์ของคุณเลย

แอปพลิเคชันนี้เชื่อมต่ออินเทอร์เน็ตเพื่อวัตถุประสงค์เดียวเท่านั้น คือการดาวน์โหลดม็อดชุมชนที่เป็นทางเลือกและแคตตาล็อกของม็อดเหล่านั้น ตามที่อธิบายไว้ในหมวด 5 คำขอเหล่านี้จะไม่รวมข้อมูลตัวละครของคุณ การตั้งค่าของคุณ หรือข้อมูลส่วนบุคคลใด ๆ เลย

## 3. การจัดเก็บข้อมูล

ข้อมูลทั้งหมดที่เกี่ยวข้องกับตัวละครและการตั้งค่าของคุณ (เช่น ธีม ภาษา การตั้งค่าการทอยลูกเต๋า ม็อดที่ติดตั้งไว้) จะถูกจัดเก็บไว้ในเครื่องบนอุปกรณ์ของคุณโดยใช้กลไกการจัดเก็บข้อมูลภายในของเบราว์เซอร์ เช่น Local Storage และ IndexedDB ข้อมูลเหล่านี้จะยังคงอยู่ในอุปกรณ์ของคุณและไม่สามารถเข้าถึงได้โดยเรา หรือบุคคลที่สาม

## 4. การควบคุมของผู้ใช้

คุณมีการควบคุมข้อมูลของคุณอย่างเต็มที่ภายในแอปพลิเคชัน คุณสามารถอัปเดตหรือลบตัวละคร การตั้งค่า และม็อดที่ติดตั้งไว้ของคุณผ่านอินเทอร์เฟซของผู้ใช้ในแอปพลิเคชัน นอกจากนี้ คุณยังสามารถลบข้อมูลแอปพลิเคชันทั้งหมดผ่านการตั้งค่าอุปกรณ์ของคุณ

## 5. การเชื่อมต่อเครือข่ายและเนื้อหาจากบุคคลที่สาม

แอปพลิเคชันนี้รองรับม็อดที่เป็นทางเลือกซึ่งสร้างขึ้นโดยชุมชน เพื่อให้ม็อดเหล่านี้พร้อมใช้งาน แอปพลิเคชันจะดำเนินการคำขอเครือข่ายดังต่อไปนี้:

- **การรีเฟรชแคตตาล็อกม็อด (อัตโนมัติ):** เมื่อแอปพลิเคชันเริ่มทำงาน แอปจะดาวน์โหลดแคตตาล็อกม็อดสาธารณะจากรีจิสทรีม็อดอย่างเป็นทางการ ซึ่งโฮสต์อยู่บน GitHub Pages (`stanislavsonder.github.io/fate-mods`) ซึ่งช่วยให้รายการใน Mod Store เป็นปัจจุบันอยู่เสมอ
- **การเรียกดู Mod Store (จากการกระทำของคุณ):** การเปิดหน้าม็อดใน Mod Store จะดาวน์โหลดคำอธิบายของม็อดนั้นจากรีจิสทรีเดียวกัน
- **การติดตั้งม็อด (จากการกระทำของคุณ):** การติดตั้งม็อด — จาก Mod Store หรือจาก URL ที่คุณระบุเอง — จะดาวน์โหลดไฟล์ของม็อด (แมนิเฟสต์ ชุดโค้ด และคำแปล) จากรีจิสทรีหรือจาก URL นั้น

สิ่งเหล่านี้เป็นคำขอดาวน์โหลดทั่วไป ซึ่งไม่มีข้อมูลตัวละคร การตั้งค่า หรือตัวระบุใด ๆ ที่แอปพลิเคชันเพิ่มเข้าไป เช่นเดียวกับการเชื่อมต่ออินเทอร์เน็ตใด ๆ ผู้ให้บริการโฮสต์ (GitHub หรือโฮสต์ของ URL ที่คุณระบุ) สามารถเห็นข้อมูลเมทาดาต้าการเชื่อมต่อมาตรฐาน เช่น ที่อยู่ IP ของคุณได้ในทางเทคนิค ซึ่งอยู่ภายใต้นโยบายความเป็นส่วนตัวของผู้ให้บริการรายนั้นเอง ไม่ใช่ของเรา

แอปพลิเคชันนี้ไม่มีการวิเคราะห์ข้อมูล ไม่มีโฆษณา และไม่มีการติดตามใด ๆ ทั้งสิ้น เราจะไม่แชร์ข้อมูลใด ๆ กับบุคคลที่สาม หรือเก็บรวบรวมข้อมูลเพื่อประโยชน์ของบุคคลที่สาม

## 6. ความเป็นส่วนตัวของเด็ก

แอปพลิเคชันนี้เหมาะสำหรับผู้ใช้ทุกวัยและไม่มีเนื้อหาที่ต้องการข้อจำกัดอายุ
